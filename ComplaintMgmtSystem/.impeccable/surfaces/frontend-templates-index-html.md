# Surface brief: landing (index) — Direction A "The Register"

Scope: public landing page only (`frontend/templates/index.html`). Persuade mode:
visitor (student or admin) must grasp within seconds that this is a live,
ranked complaint queue with transparent outcomes — then file or sign in.

## Direction contract

THESIS: The page owns one idea — the queue is the product. No marketing
banner, no feature grid; the first viewport is a working ranked register.
It refuses the category-default centered hero plus icon cards.

OWN-WORLD: Paper ground (#FAF6EF), ink text (#0F2A43), hairline rules,
slab-serif display (Bitter) for ranks and headlines, Inter for UI, system
mono for ticket IDs. One accent, oxblood (#8C2F1B), spent only on the
primary action and critical flags. Priority is always pill = tinted bg +
icon + uppercase label, never color alone. Depth from hairlines and one
soft offset shadow; no gradients, no glass, no glow.

STORY: A skeptical student learns complaints actually get resolved (ranked
rows with ages and outcomes prove it) and files in one click. An admin
sees triage discipline and signs in. Both leave knowing the mechanism:
file, rank, resolve, track.

FIRST VIEWPORT: Left column — compact masthead, one-line brief, single
"File a complaint" action, proof line with live counts. Right column —
the register: top 5 ranked rows (rank numeral, priority pill, subject,
category, age), newest-first honesty, link into full tracking. Primary
action sits left, at the end of the two-sentence brief.

FORM: Ranked-register split. User-pinned Direction A from the Phase 2
hand; concept-seed roll skipped (pinned direction beats the roll).
Signature interaction: rows resolve in place — hover reveals outcome line.

FINISH: unreviewed and undocumented is unfinished; this build ends with
the finish review, the verdict, DESIGN.md, and every shipping raster
carrying its provenance
